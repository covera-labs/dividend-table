# dividend-table

iOSアプリ「Covera」が使う、**1株配当の公開データ**を、毎日作って公開するリポジトリです。

アプリは、この表を**まるごと**ダウンロードして端末に保存し、保有数との掛け算は端末の中で行います。利用者が持っている銘柄は、どこにも送られません。

## データの出どころ

- 日本株: [EDINET](https://disclosure2.edinet-fsa.go.jp/)（金融庁）の有価証券報告書。「公共データ利用規約（PDL1.0）」に基づいて利用し、**加工して作成**しています
- 米国株: [SEC EDGAR](https://www.sec.gov/edgar)（`data.sec.gov` の XBRL データ）。SEC とは関係ありません

## 中身

| 場所 | 内容 |
|---|---|
| `scripts/edinet.py` | EDINET API のクライアント（キーとURLをログに出さない。通信の間を空ける） |
| `scripts/jp_extract.py` | 有価証券報告書のCSVから、年間・中間の1株配当、決議の表、発行済株式数を取り出す |
| `scripts/jp_rules.py` | 株式分割の影響をそろえて、載せる値を決める |
| `tests/` | 上の部品のテスト（標準ライブラリの `unittest`） |
| `data/` | 毎日の結果（日本株・米国株の表と、処理済みの書類の記録） |

## テストの動かし方

```bash
python3 -m unittest discover -s . -p "test_*.py" -t .
```

## 状態

作成中です。毎日の自動実行と、公開用の表は、まだありません。

## 分割の扱い

有価証券報告書の1株配当は、株式分割の前後の数字が混ざることがあります。次の2つで見分けます。

1. 発行済株式総数の「当期÷前期」が 0.7〜1.4 の範囲外なら、分割があった年とみなす
2. 剰余金の配当の表の「総額÷1株配当」（その配当を受けた株数）の比で、年の中で基準が混ざったかを見る

混ざっていたときは、最新の株数の基準に組み直します。読めない・確かめられない銘柄は、表に載せません。
